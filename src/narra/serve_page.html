How Narra works

1 · Source

Paste text or choose a .txt / .pdf file. PDFs are read on your machine.

2 · Format

Pick a chip (deep-dive, brief, critique, debate) or type a custom briefing. The writer turns the source into a script.

3 · Voices

The writer is the LLM (Gemini, any OpenAI-compatible endpoint, or Ollama). The voice speaks each line (edge is free; OpenAI-compatible uses /v1/audio/speech; Gemini is native). Each speaker can use a different voice.

4 · Script

Write the script, edit any line, then “Speak this script”. The episode joins the in-memory gallery — Save writes the MP3 + a JSON sidecar to your podcasts folder.

Privacy

No account, no telemetry. The only network traffic is to the writer and voice providers you configure. The gallery lives in memory and disappears when the server stops.
